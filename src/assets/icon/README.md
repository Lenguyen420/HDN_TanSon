# Icon tiện ích

Các PNG bên dưới được tách từ ảnh gốc `icon.png`, giữ nền trong suốt:

| File | Tiện ích |
| --- | --- |
| `about.png` | Giới thiệu |
| `membership-fee.png` | Hội phí — Đóng phí / Lịch sử |
| `participation.png` | Lịch sử tham gia |
| `sponsorship.png` | Lịch sử tài trợ |
| `contact.png` | Liên hệ |
| `event-assistant.png` | Trợ lý sự kiện |

Thay từng file để đổi icon, hoặc đổi đường dẫn `icon` trong `src/datas/utilities.ts`. Trường `icon` nhận đường dẫn ảnh, có thể dùng URL do API trả về.
